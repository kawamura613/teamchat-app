## 2. 今回作らないもの

### 2-1. 仕様書で指定されたもの

| 作らないもの | 理由 | 根拠 |
|:--|:--|:--|
| 新着メッセージの自動表示（画面を開いたままで届く） | 今回は画面を開き直して確認できれば十分 | 仕様書 4 |
| 通知（メール・スマートフォンへの通知） | まずは社内で使い始められる形を優先したい | 仕様書 4 |
| 1対1のダイレクトメッセージ | チャンネルでの会話に絞りたい | 仕様書 4 |
| ファイル・画像の添付 | 文章のやり取りに絞りたい | 仕様書 4 |
| メッセージへのリアクション（絵文字を付ける） | 会話ができることを優先したい | 仕様書 4 |
| 未読・既読の管理 | 同上 | 仕様書 4 |
| 管理者による全体管理（利用者の停止、他人のチャンネルの管理） | 運用が固まってから考えたい | 仕様書 4 |
| 書き込み・変更ができるAPI | 公開APIは読み取り専用と指定されている | 仕様書 3-7 |
| スマートフォン向けの表示（レスポンシブ） | 使うのはPCのブラウザのみ。画面の最小幅は1280px | 仕様書 5-2 / `design-guide.md` 3 |

### 2-2. モックアップの指定から外したもの

| 作らないもの | 理由 | 根拠 |
|:--|:--|:--|
| チャンネルの公開範囲をあとから変更する機能 | 編集画面に「公開範囲はあとから変更できません」と書かれている | `channel-edit.html` |
| Webフォント・外部CDN・画像ファイルの読み込み | 使わないと明記されている | `design-guide.md` 冒頭 |

### 2-3. 本書で追加で除外したもの（要確認）

仕様書にもモックアップにも記載がなく、こちらの判断でスコープ外としたものです。`questions.md` で確認します。

| 作らないもの | 判断の理由 | 確認 |
|:--|:--|:--|
| プロフィール編集（表示名・メールアドレス・パスワードの変更） | 仕様書・モックアップのどちらにも画面・記載なし | Q-05 |
| パスワード再設定（「お忘れの方」の導線） | `login.html` に導線がない | Q-05 |
| 退会（アカウント削除） | 記載なし。仕様書 4 の「利用者の停止」が先送りされていることとも整合 | Q-05 |
| 公開チャンネルへの参加／退出 | 公開チャンネルは「ログインした社員なら誰でも」見られるため、参加という状態を持たない | Q-06 |
| チャンネル作成者（オーナー）の譲渡 | 記載なし。「作った人だけ」という線引きが仕様書で固定されている | Q-07 |
| 返信に対する返信（スレッドの多段化） | モックアップのスレッドは1段のみ | Q-22 |
| メッセージのページ送り・無限スクロール | 1チャンネル10件前後が前提 | Q-16 |
| メンション（`@`）・引用・絵文字・装飾（太字など） | 記載なし。モックアップの本文はすべて素のテキスト | Q-20 |
| 検索の絞り込み（チャンネル・投稿者・期間）と検索履歴 | `search.html` にキーワード欄しかない | Q-27 |
| 削除したチャンネル・メッセージの復元、操作履歴の閲覧 | 「元に戻せません」「取り消せません」と明記されている | Q-11 |
| 利用者（社員）の一覧画面 | メンバー追加の検索欄以外に、人を一覧する画面がない | Q-14 |
